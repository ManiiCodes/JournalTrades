Tradovate

Connect with Tradovate sign-in

Use this for prop firm accounts (Tradeify, Lucid, Purdia). You sign in on Tradovate with the credentials your prop firm gave you.

Import a Tradovate CSV

Works for every account today. In Tradovate open Reports, then Performance, choose the account and date range, and download CSV. Times are read in your journal timezone.

Connect with an API key (personal live account only)

Tradovate only issues API keys on a live, funded brokerage account with the API Access add-on. Prop firm and evaluation accounts can't use this; use the sign-in option or CSV import for those. Your password and secret are encrypted on the server.
